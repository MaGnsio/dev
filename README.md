### This repository contains **all of my personal dotfiles**

## 📦 Structure

```
dotfiles/
├── configs/       # Cross-platform (ghostty, zsh, tmux, nvim)
├── arch/
│   ├── configs/   # Arch/Linux only (Hyprland, Waybar, Rofi, Swaync, Ly, fontconfig)
│   └── runs/      # Install + setup scripts
├── github/        # Git config and global gitignore
├── claude/        # Claude Code settings (common / personal / work)
└── scripts/       # Utility scripts (CP problem runner)
```

## 📦 Included Configurations
**Cross-platform:** `ghostty` · `zsh` + `oh-my-zsh` · `tmux` · `neovim`

**Arch/Linux:** `Hyprland` · `Waybar` · `Swaync` · `Rofi` · `Ly`
