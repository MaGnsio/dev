### This repository contains **all of my personal dotfiles**

## 📦 Included Configurations
This repository includes configuration for:
- **Window Managers**: `Hyprland`
- **Terminals**: `ghostty`
- **Shells**: `zsh`
- **Prompt**: `oh-my-zsh`
- **Editors**: `neovim`
- **Multiplexer**: `tmux`
- **Status Bar**: `waybar`
- **Notifications**: `swaync`
- **Launcher**: `rofi`
